# ZAVOA Website V3 – launch-ready

Die Website ist statisch und kann ohne Build-Schritt veröffentlicht werden.

Empfohlener einfacher Weg:
1. Konto bei Netlify erstellen.
2. Den Inhalt dieses Ordners per Drag & Drop als neue Site hochladen.
3. In Netlify unter Domain Management `zavoa.de` hinzufügen.
4. Netlify zeigt anschließend die DNS-Einträge, die bei INWX gesetzt werden müssen.
5. Nach DNS-Aktivierung stellt Netlify automatisch HTTPS bereit.

Alternativ funktioniert die Site auch bei Cloudflare Pages, GitHub Pages oder normalem Webhosting.

Vor Launch unbedingt:
- Betreiberangaben
- Kontakt-E-Mail
- Datenschutz finalisieren
